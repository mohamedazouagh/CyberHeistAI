# CyberHeistAI

CyberHeistAI is a cybersecurity-themed browser game built with HTML, CSS, and vanilla JavaScript. Players complete short logic and timing challenges while managing a rising threat meter.

## What it includes

- Three difficulty levels
- Timed objectives and interactive mini-games
- Threat and score tracking
- Optional hints and accessibility-oriented motion controls
- A local leaderboard stored in the browser

The project is entirely client-side. It does not require a backend, user account, or API key.

## Run locally

Clone the repository and open `index.html` in a browser. For consistent browser behavior, you can also serve the folder with any local static-file server.

## Technical focus

The code demonstrates DOM state management, event-driven interactions, responsive styling, browser storage, timers, and game-state transitions without a JavaScript framework.

## Project status

This is an academic project retained as a working example of earlier front-end development. The repository describes the implementation as it exists and does not claim production security tooling or real intrusion capabilities.
